# CLIENT MODULE ARCHITECTURE (Fase 4.3)\n\nEl módulo de Clientes es el pilar maestro de la plataforma.\n\n## 1. Tipología de Cliente y Requisitos Documentales\nLa estructura base impone una bifurcación estricta dependiente del \`client_type\`:\n\n### Persona Física\n- **Obligatorio**: Nombre, Apellidos, RFC (13 caracteres), CURP.\n- **Documentos Exigidos**: RFC, Constancia Fiscal, INE, CURP.\n\n### Persona Moral\n- **Obligatorio**: Razón Social (sin S.A. de C.V.), RFC (12 caracteres), Representante Legal.\n- **Documentos Exigidos**: RFC, Constancia Fiscal, Acta Constitutiva, Poder del Representante, INE del Representante.\n\n## 2. Llaves y Master Data Management\n- La **Llave Primaria Técnica (PK)** es siempre el \`id\` (UUID nativo de PocketBase).\n- El **RFC** opera como **Llave Única de Negocio**, impidiendo que dos registros coexistan con el mismo RFC. Se ejecutan búsquedas "Soft Match" contra el RFC y Razón Social antes de permitir crear al cliente.\n\n## 3. Expediente Único (360° View)\nEl ecosistema central del cliente contiene las siguientes pestañas (\`DsTabs\`):\n- **General**: Datos fiscales, contacto, dirección.\n- **Documentos**: Auditoría documental exigida según el tipo de persona.\n- **Información Bancaria**: Referencias bancarias y estatus de asignación/validación financiera.\n- **Actividad / Timeline**: Eventos históricos del cliente.\n- **Relaciones Futuras (Preparadas)**: Cotizaciones, Contratos, Pagos, Facturas.\n\n## 4. Matriz de Permisos (Zero Trust)\nEl módulo responde estrictamente al siguiente subconjunto del catálogo RBAC:\n- \`client.read\`: Permite listar y ver el perfil general.\n- \`client.create\`: Permite ingresar nuevos prospectos.\n- \`client.update\`: Permite modificar la data de contacto.\n- \`client.delete\`: Permite deshabilitar el registro (Soft Delete).\n- \`client.documents.read\`: Autoriza previsualizar PDFs o Imágenes del cliente.\n- \`client.documents.upload\`: Autoriza inyectar nuevos documentos al expediente.\n- \`client.banking.read\`: Autoriza ver la referencia asignada (solo Finanzas o Comercial).\n- \`client.banking.update\`: Autoriza conciliar o asignar la referencia bancaria única (Finanzas).
