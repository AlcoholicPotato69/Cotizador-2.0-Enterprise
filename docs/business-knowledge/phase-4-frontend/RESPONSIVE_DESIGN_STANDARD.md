# RESPONSIVE DESIGN STANDARD (Fase 4.1)

## Breakpoints y Grid
- **Mobile (< 640px)**: 1 columna. App Shell colapsa el Sidebar en un *Drawer* hamburguesa. Tablas cambian a vista de *Cards* verticales.
- **Tablet (640px - 1024px)**: 2 columnas. Sidebar minimizado a iconos.
- **Laptop (1024px - 1280px)**: Sidebar completo, Dashboards y Calendarios con scroll horizontal dinámico.
- **Desktop (> 1280px)**: Aprovechamiento del *Ultra-Wide* para métricas adicionales y visores de PDF *Side-by-Side*.
