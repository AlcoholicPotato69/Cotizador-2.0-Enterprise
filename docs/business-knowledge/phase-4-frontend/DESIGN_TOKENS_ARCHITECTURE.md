# DESIGN TOKENS ARCHITECTURE

## Variables Core (CSS Custom Properties)
- `--color-primary`: Cambia según Tenant (Rojo vs Café).
- `--color-surface`: Blancos absolutos (Light) / Negros Matte (Dark).
- `--radius-md`: 6px para botones (*Linear-style*).
- `--font-sans`: Inter o equivalente.
- `--shadow-sm`: Sutil, imitando elevación física suave.
