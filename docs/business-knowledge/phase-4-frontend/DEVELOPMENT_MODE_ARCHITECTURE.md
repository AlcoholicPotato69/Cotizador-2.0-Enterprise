# DEVELOPMENT MODE ARCHITECTURE (Fase 4.3.2)\n\nEste documento define la estructura y reglas del **Development Mode Framework**, una capa de herramientas exclusivas para los ingenieros, inyectadas únicamente cuando \`import.meta.env.DEV\` es \`true\`.\n\n## 1. Segregación de Entornos\n- **DEV**: Entorno local \`localhost:5173\`. Cuenta con base de datos SQLite efímera, usuarios mockeados (\`MockAuth\`), y la barra de herramientas flotante (\`DevToolbar\`). Es el laboratorio de experimentación visual.\n- **STAGING**: Réplica del entorno de Producción conectado a un PocketBase remoto de QA. Los datos no son efímeros, pero el envío de correos, integraciones bancarias y facturación real están inhabilitados o apuntan a *Sandboxes* externos.\n- **PRODUCTION**: Entorno final, blindado. El código del \`DevToolbar\`, los datos mock y el \`PermissionSimulator\` son automáticamente *purgados* en la fase de Build del bundler (Vite), asegurando que el *bundle* de producción sea ligero y seguro.\n\n## 2. DevToolbar (Barra de Herramientas Local)\nUna barra fija (flotante) que solo aparece en entorno DEV, permitiendo a los ingenieros saltar de contexto al instante:\n- **Tenant Switcher**: Cambiar entre \`PM\` (Plaza Mayor) y \`CP\` (Casa de Piedra) forzando el repintado masivo de *Design Tokens* y re-cálculo de reglas de negocio.\n- **Mock Auth**: Selector (Dropdown) que permite cambiar el \`ActiveUser\` al vuelo (ej. de \`SuperAdmin\` a \`Finanzas PM\`), disparando las reglas de RBAC.\n- **Theme Switcher**: Alternar Dark/Light mode al instante para validar contraste.\n- **Seed Trigger**: Ejecuta comandos simulados para popular el \`clientStore\`, \`contractStore\`, etc., con *Demo Data*.\n\n## 3. Devtools Center (\`/devtools\`)\nUna ruta oculta exclusiva de DEV que contiene utilerías pesadas:\n- **Permission Sandbox**: Matriz visual para prender/apagar checkboxes de \`permissionsStore\`. Útil para validar cómo reaccionan las Vistas (*Zero Trust*).\n- **Notification Trigger**: Un botón para simular la llegada asíncrona (SSE/WebSocket) de una notificación del servidor, probando el \`DsNotificationPanel\`.\n- **Stores Inspector**: Dump de los estados globales de Pinia en crudo (JSON).
