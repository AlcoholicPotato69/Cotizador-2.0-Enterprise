# PROJECT BASELINE

## Authority: TECHNICAL DIRECTOR & PROGRAM GOVERNANCE
## Date: 2026-05-23
## Status: FROZEN / REBUILDING

### 1. Project Philosophy
- **Toda afirmación debe tener fuente verificable.**
- Fuentes válidas: Código fuente, Esquema PocketBase, Migraciones, Hooks, SQLite, Arquitectura oficial, Documentación oficial aprobada.
- Fuentes NO válidas: Certificaciones previas sin evidencia, Suposiciones, Reportes generados por IA sin validación, Arquitecturas hipotéticas.

### 2. State of the Union
- **Codebase:** All existing code is completely frozen.
- **Certifications:** All prior certifications and QA reports are officially marked as **UNRELIABLE** and must be re-validated.
- **Architecture:** Existing architecture documentation is preserved but requires validation by the Enterprise Architect against the actual code.
