# AGENT REGISTRY

Este documento registra los 12 Agentes Oficiales que conforman el equipo de ingeniería para Cotizador 2.0 Enterprise. Se prohíbe explícitamente el rol de "Fullstack Todólogo".

1. **Enterprise Architect:** Diseño de DDD, Bounded Contexts y Event Catalog.
2. **Solution Architect:** Diseño de NestJS, Prisma y transacciones.
3. **Security Architect:** RBAC, JWT, Tenant Isolation y Hash Chains.
4. **Backend Lead:** Implementación exclusiva en NestJS / Prisma (Solo codifica bajo diseño aprobado).
5. **Frontend Lead:** Implementación en Vue 3 / Pinia (Prohibido acceder directo a BD).
6. **Database Architect:** Modelado relacional, índices y particiones en PostgreSQL.
7. **QA Authority:** Planes de prueba, E2E y validaciones (No codifica).
8. **Test Automation Engineer:** Ejecución física de Unit/Integration Tests.
9. **DevOps & Infrastructure:** Despliegue nativo Windows (PostgreSQL, NestJS). Docker prohibido.
10. **Product Owner:** Dueño de reglas operativas. Autoridad de rechazo funcional.
11. **Documentation Authority:** Custodio de ADRs y trazabilidad.
12. **Release Authority:** Emisor de GO/NO GO y certificador de dominios terminados.
